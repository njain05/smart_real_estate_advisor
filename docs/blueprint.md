# **App Name**: Smart Real Estate Advisor

## Core Features:

- User Authentication: User authentication with email/password and Google Sign-In.
- Property Listings: Display property listings with search and filter options.
- Favorites: Enable users to save favorite properties.
- AI Legal Tips: Provide AI-driven legal tips for each property, using location data as a tool.
- Contact Seller: Allow users to contact the seller of a property through a simple form.
- Role-Based Access: Implement basic role-based access control (buyer, seller, agent).
- Display legal resources: Display Legal Resources
- Property Recommendation Engine: Use AI to recommend properties based on user preferences, search history, and saved favorites.
- Mortgage & EMI Calculator: Let users estimate loan affordability directly in the app.
- Map Integration (Google Maps / Mapbox): Show property locations, nearby schools, hospitals, legal offices, etc.
- Smart Notifications: Push/email notifications for new properties matching saved searches or price drops.
- Property Verification Badge: Verified sellers or legally cleared properties get a badge for trust-building.
- Multi-language Support: Useful for expanding into different regions.
- Chatbot Assistant: AI-driven assistant to answer FAQs about buying, renting, or legal processes.
- Document Upload & Verification: Sellers can upload ownership/legal documents for AI-powered pre-checks.
- Analytics Dashboard (for Agents/Sellers): See views, inquiries, and interest trends for their listings
- AI-Powered Legal Summaries: Simplify long property documents into bullet points.
- Region-Specific Legal Compliance Alerts: Example: “This property is in Punjab, so stamp duty = X%.”
- In-App Lawyer Connect: Partner with legal professionals for one-click consultations.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and security, reflecting the app's real estate and legal focus.
- Background color: Light blue (#E8EAF6), a desaturated variant of the primary color, providing a calm and professional backdrop.
- Accent color: Purple (#7E57C2) to highlight key interactive elements.
- Headline font: 'Space Grotesk' (sans-serif), a font that has a computerized feel for the headlines. Body font: 'Inter' (sans-serif) to ensure readability for legal information and property descriptions.
- Use modern, clean icons for navigation and property features.
- Implement a responsive grid layout to adapt to different screen sizes.
- Subtle animations for transitions and loading states.
- Dark Mode (trustworthy + modern).
- Micro-animations for property cards (hover, like/favorite, swipe).
- Skeleton Loaders (instead of spinners) for smoother feel.
- Interactive Legal Tips Cards with expandable sections (like “Know More”).
- Ratings for sellers/agents. Legal verification badges.
