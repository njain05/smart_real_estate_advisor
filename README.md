# 🏠 Smart Real Estate Advisor

Your intelligent partner in property decisions. A modern, AI-powered real estate platform built with Next.js 15.

## ✨ Features

- **AI-Powered Legal Advice** - Get location-specific legal tips for property transactions
- **Smart Property Recommendations** - AI analyzes your preferences to find perfect matches
- **Property Listings** - Browse verified properties with advanced search and filtering
- **Document Verification** - Verify property documents securely
- **Mortgage Calculator** - Financial planning tools for property investment
- **Analytics Dashboard** - Property insights and market data
- **Lawyer Connection** - Connect with legal professionals

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- Google AI API key

### Installation
1. Clone the repository
2. Install dependencies: `npm install`
3. Create `.env.local` with your Google AI API key
4. Run development server: `npm run dev`

The app will be available at **http://localhost:9002**
